## Structure
Each problem gets its own folder named `<number>-<slug>`, matching how LeetCode names it. Inside is just the solution file, no extra fluff.

New folder? Add its name and topic to `topics.json`, push, and the table above rebuilds itself via a GitHub Action.

## Why
Keeping this so I have a record of patterns I've covered and can revisit when I'm stuck on something similar down the line.
